# Code Reference Map — "Show Me Where X Is Implemented"

> **Owner:** SRE Agent platform team.
> **Last Verified:** 2026-08-09 — every citation below was re-opened and confirmed against the
> live repository at `~/projects/sre-agent-gateway` while writing this page (not copied from
> memory of other docs).
> **Purpose:** the single lookup table for "where in the code does X actually happen?" — so you
> never have to guess or ask an AI where something lives. Every cell is either a real, verified
> value or an honest **"none found"** / **"n/a"**. If a row's status label seems surprising,
> cross-check it against [Implemented vs Planned — Master Status Matrix](../management/implemented-vs-planned-matrix.md),
> which is the authoritative status source this page must never contradict.

## How to read this table

- **Main Code** — the real file(s) that implement the capability.
- **Function** — the real function/class name, with an approximate line range where useful.
  Line numbers drift as the code changes — if a number looks off, trust the function name and
  re-grep, don't trust the number blindly.
- **Config** — the env var or Terraform-driven setting that controls behavior, or `n/a` if the
  capability isn't configurable.
- **Terraform** — the real `.tf` file/resource that provisions or wires this capability, or
  `n/a` if there's no infrastructure involved.
- **Tests** — a real `file:test_function`, or **"none found"** stated plainly when no direct
  test exists. This repo has a genuine test-coverage gap on 6 of 9 LangGraph nodes — see the
  [Master Status Matrix](../management/implemented-vs-planned-matrix.md) — and this table does
  not paper over that.
- **Runtime Proof** — a command or query you can actually run today to prove the capability
  works, not a hypothetical.

## Notes on rows with no dedicated test

Several rows above honestly say **"none found."** This is not a documentation gap — it's a real,
current test-coverage gap confirmed by direct grep against the repo (see the [Master Status
Matrix](../management/implemented-vs-planned-matrix.md) and the [Documentation Validation
Report](../../archive/SUPERSEDED_2026-08-20_DOCUMENTATION-VALIDATION-REPORT.md)'s 2026-08-09 pass). Only 3 of 9 LangGraph nodes
(`context_resolver`, `mcp_router`, `rca_builder`) have direct test coverage; no test in the repo
exercises the compiled full graph (`compile_graph()` / `graph.invoke()`). If you're picking up
test-coverage work, `loop_controller`, `task_planner`, `evidence_extractor`, `task_evaluator`,
`tool_executor`, and `input_normalizer` are the six real gaps.
